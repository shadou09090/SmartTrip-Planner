# SmartTrip-Planner

Esta es una aplicación web diseñada para ayudar a los usuarios a planificar viajes de manera eficiente y personalizada. A través del uso de APIs externas como Google Maps y servicios de vuelos, el sistema genera itinerarios inteligentes basados en los intereses, presupuesto y tiempo disponible del usuario.

El objetivo es centralizar la información necesaria para planear un viaje en una sola plataforma, facilitando la toma de decisiones y mejorando la experiencia del usuario.
