# SmartTrip-Planner

Esta es una aplicación web diseñada para ayudar a los usuarios a planificar viajes de manera eficiente y personalizada. A través del uso de APIs externas como Google Maps y servicios de vuelos, el sistema genera itinerarios inteligentes basados en los intereses, presupuesto y tiempo disponible del usuario.

El objetivo es centralizar la información necesaria para planear un viaje en una sola plataforma, facilitando la toma de decisiones y mejorando la experiencia del usuario.

---

## 🚀 Cómo Iniciar el Frontend (React + Vite)

### Requisitos Previos
- **Node.js** (v18 o superior)
- **npm** (v9 o superior)

### Pasos para Ejecutar en Desarrollo

1. **Navega al directorio del frontend:**
   ```bash
   cd frontend
   ```

2. **Instala las dependencias (si no lo has hecho aún):**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Abre en el navegador:**
   La aplicación estará disponible automáticamente en:
   [http://localhost:3000](http://localhost:3000)

### Comandos Disponibles

En la carpeta `frontend/`:
- `npm run dev`: Inicia el servidor de desarrollo de Vite con recarga rápida (HMR).
- `npm run build`: Compila la aplicación optimizada para producción en la carpeta `dist/`.
- `npm run preview`: Previsualiza localmente la compilación de producción.

## 🛠️ Tecnologías del Proyecto

- **Frontend**: React 18, Vite, Lucide React (iconos), CSS Modulado.
- **Backend**: Java, Spring Boot, Maven (ubicado en `backend/`).
